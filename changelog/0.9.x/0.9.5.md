# 0.9.5 — 2026-08-21

## Added

- **Project contribution guidance** now includes `CONTRIBUTING.md`, `CODE_OF_CONDUCT.md`, and a dedicated `security@caseyjhand.com` vulnerability-reporting address.

## Changed

- **`@cyanheads/mcp-ts-core` 0.12.3 adoption** updates the server to MCP SDK 2.0 conventions across tests, packaging checks, project skills, and agent documentation.
- **Test type-checking** now includes `tests/**/*`, with production emission isolated in `tsconfig.build.json` and a shared `firstText()` assertion helper for MCP SDK 2 content blocks.
- **Production containers** now build on Bun 1.4.0 and omit optional framework peers from the runtime dependency graph.
- **Project tooling** now recognizes the MCP SDK 2 runtime package, excludes ignored directories correctly from `docs/tree.md`, and matches the framework's handler-only tool contract.
