# 0.9.7 — 2026-10-08

## Changed

- **`@cyanheads/mcp-ts-core` 0.13.14 adoption** changes what a client sees on a call, inherited from the framework rather than authored in this server's source. Numeric strings (`modelYear: "2020"`, `limit: "2"`) and `null` for an optional argument are repaired before validation, and `-32602` rejections are bounded in size (0.13.14). Tool error results carry `data.requestId` and end with `request <id>` (0.13.10). Error data no longer carries server stack traces (0.13.7), request context (0.13.8), or `data.rootCause` (0.13.13). Tool input and output schemas are unchanged.
- **`ctx.fail` calls** in the tool handlers no longer forward `ctx.recoveryFor(...)`; the framework fills the declared recovery hint itself (0.13.10), and callers see the same hint text as before.
- **Docker image** installs production dependencies in a new `deps` stage that runs on the build platform and cross-installs for the target with `--os`/`--cpu`, so the multi-arch build no longer runs Bun under QEMU. Two new scripts, `scripts/install-otel.ts` and `scripts/prune-musl-packages.ts`, drive the OpenTelemetry install and drop musl-only native packages from the Debian runtime image. The Bun 1.4.2 pin follows the framework scaffold across `packageManager`, the Docker base images, and the README badge.
- **`server.json`** npm entries launch with `runtimeHint: "npx"` and no `packageArguments`; the HTTP entry sets `MCP_TRANSPORT_TYPE=http` as an environment variable.
- **`package.json`** adds a `start` script and excludes `dist/*.mcpb` from the published `files`.
- **`.mcpbignore`** also excludes `docs/idea.md`, `logs/`, `.cache/`, `coverage/`, and `tests/` from the bundle; `.gitignore` and `.dockerignore` cover every `.env*` file except the `.env.example`, `.env.template`, and `.env.sample` templates.
- **CodeQL workflow** runs one job per language, uploading under `/language:<language>`.
- **Release PR mode** declared in `CLAUDE.md` and `AGENTS.md` (`## Publishing`) is now `gated`: wrapup, `release-pr-review`, and release run as separate steps instead of straight-through.
- **Development skills and maintenance scripts** (`framework-skills/`, `devcheck`, `lint-mcp`, `lint-packaging`, `check-skill-versions`, `check-framework-antipatterns`, `release-github`) synced to the framework 0.13.14 set.
- **`CLAUDE.md`, `AGENTS.md`, `README.md`, `.env.example`** updated to match, including documentation of the optional `LOG_TOOL_FAILURE_PAYLOADS`, `OTEL_ENABLED`, `MCP_REQUEST_STATE_KEY`, and `OTEL_EXPORTER_OTLP_LOGS_ENDPOINT` settings; the MCP SDK badge reads 2.3.1.
