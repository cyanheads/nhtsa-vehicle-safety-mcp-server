# 0.9.1 — 2026-07-30

## Added

- `nhtsa_get_vehicle_safety` recall entries now carry `manufacturer`, `consequence`, `parkOutSide`, and `overTheAirUpdate` — previously dropped between the upstream response and the output schema. ([#26](https://github.com/cyanheads/nhtsa-vehicle-safety-mcp-server/issues/26))
- `nhtsa_get_vehicle_safety` gained an `enrichment` block: `effectiveQuery` echoes the queried vehicle, and `notice` points at `nhtsa_lookup_vehicles` when NCAP, recalls, and complaints all loaded and matched nothing. ([#29](https://github.com/cyanheads/nhtsa-vehicle-safety-mcp-server/issues/29))

## Changed

- `format()` renders every recall advisory flag explicitly — `Do not drive: no` / `Park outside: yes` / `Over-the-air update: no` — instead of omitting flags NHTSA set to `false`. ([#26](https://github.com/cyanheads/nhtsa-vehicle-safety-mcp-server/issues/26))
- `format()` renders every row of the complaint component breakdown instead of truncating at 10; the section heading changed from "Top Components" to "Components". ([#20](https://github.com/cyanheads/nhtsa-vehicle-safety-mcp-server/issues/20))

## Fixed

- `RolloverPossibility: 0.0` is no longer reported as a real rollover probability for an untested variant — the value is kept only when `RolloverRating` reflects a genuine rating. ([#28](https://github.com/cyanheads/nhtsa-vehicle-safety-mcp-server/issues/28))
- A vehicle query matching zero NCAP variants now reports `sectionStatus.safetyRatings: 'available'` with an empty array, instead of the misleading `'unavailable'` status a fetch failure produces. ([#29](https://github.com/cyanheads/nhtsa-vehicle-safety-mcp-server/issues/29))
