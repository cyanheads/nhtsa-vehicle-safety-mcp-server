# 0.9.3 — 2026-07-30

## Changed

- `nhtsa_search_recalls` and `nhtsa_get_vehicle_safety` render `parkIt`, `parkOutSide`, and `overTheAirUpdate` through a shared `formatRecallAdvisories()` in `format.ts`, so an explicit `false` reads as "no" instead of being omitted; a recall with none of the flags set reports "None reported by NHTSA". ([#21](https://github.com/cyanheads/nhtsa-vehicle-safety-mcp-server/issues/21))
- `nhtsa_decode_vin` states a clean decode (`errorCode: "0"`) with a **Decode status** line instead of rendering nothing; only a nonzero `errorCode` still renders as **Warning**. ([#21](https://github.com/cyanheads/nhtsa-vehicle-safety-mcp-server/issues/21))
- `nhtsa_search_complaints` adds a `Reported:` line showing `crash`, `fire`, `numberOfInjuries`, and `numberOfDeaths` whenever NHTSA sent any of them, `false`/`0` included. ([#21](https://github.com/cyanheads/nhtsa-vehicle-safety-mcp-server/issues/21))
- `modelYear` is now `z.number().int()` on `nhtsa_decode_vin`, `nhtsa_get_safety_ratings`, `nhtsa_get_vehicle_safety`, `nhtsa_lookup_vehicles`, `nhtsa_search_complaints`, and `nhtsa_search_recalls` — a fractional year is rejected at validation instead of reaching NHTSA, where it failed inconsistently by endpoint. `docs/design.md`'s parameter tables updated to match. ([#22](https://github.com/cyanheads/nhtsa-vehicle-safety-mcp-server/issues/22))
- `nhtsa_search_complaints` and `nhtsa_search_investigations` now notice an out-of-range pagination offset (`No results for this page (offset N, limit N). N total — try a smaller offset.`) instead of returning a silent empty page; `nhtsa_lookup_vehicles` was refactored onto the same `outOfBoundsMessage()` helper, now shared in `format.ts`. ([#31](https://github.com/cyanheads/nhtsa-vehicle-safety-mcp-server/issues/31))

## Fixed

- `getComplaintsByVehicle` incident-date normalization no longer drops genuine dates. It previously discarded every `dateOfIncident` before 1990 to filter NHTSA's `12/31/1969` epoch sentinel, which also discarded real 1949–1989 incidents. It now matches the two literal epoch-placeholder date strings (`1969-12-31`, `1970-01-01`) and NHTSA's separate 1901 placeholder (spread across at least eight distinct 1901 dates) by value, leaving every other date — including real 1970s–80s incidents — untouched. `dateComplaintFiled` was never subject to this rule and is unaffected. ([#32](https://github.com/cyanheads/nhtsa-vehicle-safety-mcp-server/issues/32))
