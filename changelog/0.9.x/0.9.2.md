# 0.9.2 — 2026-07-30

## Added

- `nhtsa_search_recalls` campaign lookups now return `affectedVehicles[]` — every distinct make/model/model-year the campaign covers — and `investigationId`, the linked NHTSA action number. ([#24](https://github.com/cyanheads/nhtsa-vehicle-safety-mcp-server/issues/24), [#30](https://github.com/cyanheads/nhtsa-vehicle-safety-mcp-server/issues/30))
- `nhtsa_search_investigations` gained an `nhtsaId` filter — exact, case-insensitive, whole-ID match — closing the recall-to-investigation round trip; combining it with another filter raises a `mode_conflict` error. ([#30](https://github.com/cyanheads/nhtsa-vehicle-safety-mcp-server/issues/30))
- `nhtsa_lookup_vehicles` `manufacturer` operation now walks VPIC pages up to a 500-record cap and discloses a reached cap via `truncated`/`shown`/`cap`. ([#27](https://github.com/cyanheads/nhtsa-vehicle-safety-mcp-server/issues/27))

## Changed

- `nhtsa_search_recalls` campaign lookups: `totalCount` derives from the collapsed vehicle set instead of a hardcoded `1`, and `subject` is removed from the output schema — the current `/recalls/campaignNumber` endpoint returns no such field. ([#24](https://github.com/cyanheads/nhtsa-vehicle-safety-mcp-server/issues/24))
- `nhtsa_search_recalls`: NHTSA's `"9999"` placeholder model year is dropped from `affectedVehicles[]` instead of rendered as a real year. ([#24](https://github.com/cyanheads/nhtsa-vehicle-safety-mcp-server/issues/24))
- `nhtsa_search_complaints`: `dateOfIncident` and `dateComplaintFiled` normalize to ISO `YYYY-MM-DD`, matching recall dates. ([#25](https://github.com/cyanheads/nhtsa-vehicle-safety-mcp-server/issues/25))

## Fixed

- `nhtsa_search_recalls` campaign lookup returned one of N upstream rows and discarded the affected-vehicle list. ([#24](https://github.com/cyanheads/nhtsa-vehicle-safety-mcp-server/issues/24))
- `nhtsa_lookup_vehicles` `manufacturer` operation capped at VPIC page 1 and reported that page's count as `totalCount`. ([#27](https://github.com/cyanheads/nhtsa-vehicle-safety-mcp-server/issues/27))
