# 0.11.0 — 2026-11-03

## Added

- **`nhtsa_search_recalls` broad search** by `make`, `model`, `modelYear`, and `dateRange` without a campaign number or full vehicle, served from NHTSA's recall flat files, newest first, paged with `limit` (default 20, max 50) and `offset`. ([#37](https://github.com/cyanheads/nhtsa-vehicle-safety-mcp-server/issues/37))
- **`nhtsa_lookup_vehicles` `operation: "dataset_models"`** (`make` and `modelYear` required) lists the model names NHTSA's complaint, NCAP, and VPIC lists carry, each tagged in `listedBy`; VPIC models are kept only when their make name equals the requested make. Empty-result notices on the other tools point to it. ([#47](https://github.com/cyanheads/nhtsa-vehicle-safety-mcp-server/issues/47))
- **`nhtsa_decode_vin` driver-assistance fields**: `crashImminentBraking`, `dynamicBrakeSupport`, `pedestrianAutomaticEmergencyBraking`, `forwardCollisionWarning`, `laneDepartureWarning`, `laneKeepingAssistance`, `laneCenteringAssistance`, `blindSpotWarning`, `blindSpotIntervention`, `rearCrossTrafficAlert`, `backupCamera`, `rearAutomaticEmergencyBraking`, `parkingAssist`, `adaptiveCruiseControl`, `tpmsType`, and `airBagLocSeatCushion`, also listed under Safety Equipment. ([#50](https://github.com/cyanheads/nhtsa-vehicle-safety-mcp-server/issues/50))
- **`nhtsa_decode_vin` accepts several VINs in one string** separated by spaces, semicolons, or commas, and a `VIN,YYYY` form giving one VIN its own model year.
- **`nhtsa_search_investigations` `modelYear` filter**; `make`, `model`, and `modelYear` must match the same vehicle association, and results are ordered by `openDate` descending, then `nhtsaId` descending, undated last. ([#51](https://github.com/cyanheads/nhtsa-vehicle-safety-mcp-server/issues/51))
- **`nhtsa_search_investigations` `includeSummary`** (default `false`) returns full summaries in search rows. ([#52](https://github.com/cyanheads/nhtsa-vehicle-safety-mcp-server/issues/52))
- **`NHTSA_CLAMP_LIMITS`** (default `true`): an over-cap `limit` (complaints, investigations, and recalls 50; lookup 200) is clamped with a notice, and `nhtsa_decode_vin` decodes the first 50 VINs and returns the rest in `deferredVins`. `false` rejects with `limit_too_large` or `batch_too_large`. ([#53](https://github.com/cyanheads/nhtsa-vehicle-safety-mcp-server/issues/53))
- **Published skill** `skill://nhtsa-vehicle-safety-guide/SKILL.md` in `resources/list`, shipped in the npm package, Docker image, and `.mcpb` bundle.

## Changed

- **Breaking: `nhtsa_search_investigations` rows replace the scalar `manufacturer` and `recallCampaign` with `manufacturers[]` and `recallCampaigns[]`** holding every distinct value across the investigation's association rows. ([#48](https://github.com/cyanheads/nhtsa-vehicle-safety-mcp-server/issues/48))
- **Breaking: `nhtsa_search_investigations` search rows omit `summary` unless `includeSummary: true`**; `nhtsaId` mode always returns it, and the `limit` maximum is 50 (was 25). ([#52](https://github.com/cyanheads/nhtsa-vehicle-safety-mcp-server/issues/52))
- **`nhtsa_get_vehicle_safety`, `nhtsa_search_complaints`, and `nhtsa_get_safety_ratings` empty-result notices** name the other model names NHTSA may file a vehicle under and the `dataset_models` lookup; `nhtsa_get_vehicle_safety` also fires one when only some sections come back empty. ([#47](https://github.com/cyanheads/nhtsa-vehicle-safety-mcp-server/issues/47))
- **`limit` inputs accept any positive whole number** in the schema; the cap applies in the handler. ([#53](https://github.com/cyanheads/nhtsa-vehicle-safety-mcp-server/issues/53))
- **Recall and investigation flat files** load through a shared streaming cache (24-hour TTL) that copies each retained field out of the decoded text. A bulk file that doesn't unzip, or unzips to no rows, fails `ServiceUnavailable` and caches nothing. ([#54](https://github.com/cyanheads/nhtsa-vehicle-safety-mcp-server/issues/54))

## Fixed

- **Complaint component names containing `, `** (`SERVICE BRAKES, HYDRAULIC`) stay whole in `componentBreakdown` and the `component` filter, and a filter that excludes every complaint gets its own notice. ([#46](https://github.com/cyanheads/nhtsa-vehicle-safety-mcp-server/issues/46))
- **`nhtsa_decode_vin` rejects with `invalid_vin`** VINs it used to decode wrongly: 18 or more characters, a partial VIN joined with others in one string, and characters outside A-Z, 0-9, and `*`. Joined full VINs now each decode. ([#49](https://github.com/cyanheads/nhtsa-vehicle-safety-mcp-server/issues/49))
- **Recalls with null `Summary`, `Consequence`, or `Remedy`** return the campaign with those fields omitted instead of failing output validation in `nhtsa_search_recalls` and `nhtsa_get_vehicle_safety`. ([#55](https://github.com/cyanheads/nhtsa-vehicle-safety-mcp-server/issues/55))
- **A 6-character `campaignNumber`** returns every campaign it prefixes, each built from its own rows, and `totalCount` counts campaigns. ([#57](https://github.com/cyanheads/nhtsa-vehicle-safety-mcp-server/issues/57))
