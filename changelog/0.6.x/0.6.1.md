# 0.6.1 — 2026-04-20

## Added

- All tool handlers now propagate `ctx.signal` through the NHTSA service layer for clean cancellation
- `nhtsa_search_investigations` now returns `statusName` alongside `status` and renders both in `format()`
- `nhtsa_lookup_vehicles` now surfaces `Make ID`, `Manufacturer ID`, and per-type `Vehicle Type ID` in rendered output
- `nhtsa_get_safety_ratings` now renders `combinedBarrierPoleFront` / `combinedBarrierPoleRear` star ratings
- `nhtsa_get_vehicle_safety` complaint component breakdown now shows injury and death counts per component

## Changed

- Bumped `@cyanheads/mcp-ts-core` ^0.5.3; `NhtsaService.fetchJson` uses `AbortSignal.any` and `node:timers/promises`
- `nhtsa_decode_vin` warning line now includes the VPIC `errorCode`
- `nhtsa_get_vehicle_safety` do-not-drive advisory renders as `PARK IT — DO NOT DRIVE`
- Refreshed `add-tool`, `api-config`, `design-mcp-server`, `field-test`, `maintenance`, `polish-docs-meta`, `setup` skills

## Removed

- Unused `NhtsaService.getRecallsPaginated` method
