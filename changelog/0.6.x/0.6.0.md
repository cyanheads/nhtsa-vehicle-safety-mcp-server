# 0.6.0 — 2026-04-19

## Added

- `nhtsa_search_complaints` now supports `limit` (default 20, max 50) and `offset` pagination ([#4](https://github.com/cyanheads/nhtsa-vehicle-safety-mcp-server/issues/4))
- `nhtsa_lookup_vehicles`, `nhtsa_get_safety_ratings`, and `nhtsa_search_investigations` now surface an optional `message` field when the result set is empty ([#7](https://github.com/cyanheads/nhtsa-vehicle-safety-mcp-server/issues/7))
- `combinedBarrierPoleFront` and `combinedBarrierPoleRear` on `nhtsa_get_vehicle_safety`'s `sideCrash` ([#3](https://github.com/cyanheads/nhtsa-vehicle-safety-mcp-server/issues/3))

## Changed

- Bumped `@cyanheads/mcp-ts-core` ^0.3.8; `typescript` ^6.0.3
- Removed stale transitive-dependency overrides
- Refreshed `add-tool` (v1.4) and `design-mcp-server` (v2.3) skills

## Fixed

- `nhtsa_get_vehicle_safety` now marks `sectionStatus.safetyRatings` as `unavailable` when NCAP returns no variants ([#2](https://github.com/cyanheads/nhtsa-vehicle-safety-mcp-server/issues/2))
- `nhtsa_search_complaints` no longer passes Unix-epoch `dateOfIncident` values through to consumers ([#5](https://github.com/cyanheads/nhtsa-vehicle-safety-mcp-server/issues/5))
