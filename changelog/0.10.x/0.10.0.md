# 0.10.0 — 2026-10-18

## Added

- **`nhtsa_search_investigations`** accepts inclusive `openDateRange` and `closeDateRange` filters, combined with other search criteria before counting and pagination. Active bounds exclude records without a usable corresponding date and conflict with exact-ID mode. ([#38](https://github.com/cyanheads/nhtsa-vehicle-safety-mcp-server/issues/38))

## Changed

- **Recall date bounds now require calendar-valid YYYY-MM-DD dates; full ISO timestamps are rejected.** Blank bounds are unset, inverted ranges fail before upstream work, and endpoints are inclusive. ([#35](https://github.com/cyanheads/nhtsa-vehicle-safety-mcp-server/issues/35))
- **NCAP and lookup input modes** now reject redundant as well as conflicting arguments: use `vehicleId` alone or vehicle criteria; supply only filters used by the selected lookup operation. Optional blank strings are unset. ([#36](https://github.com/cyanheads/nhtsa-vehicle-safety-mcp-server/issues/36))
- **Development runtime and guidance** use Bun 1.4.3 in the package manager pin and all Docker stages, with synchronized framework API references and release workflow guidance.

## Fixed

- **Recall filtering** applies received-date bounds in campaign mode, echoes active bounds, and distinguishes date-filtered empty results from genuine campaign or vehicle misses.
- **Required vehicle names and VIN batches** reject blank identifiers before upstream work; a blank VIN entry rejects the whole batch instead of silently shortening it.
- **Pagination text** renders past-end recovery once across lookup, complaint, and investigation responses, including capped manufacturer results. ([#39](https://github.com/cyanheads/nhtsa-vehicle-safety-mcp-server/issues/39))
- **Complaint component text** includes all four computed severity totals, including zeros, independently of narrative pagination. ([#40](https://github.com/cyanheads/nhtsa-vehicle-safety-mcp-server/issues/40))
- **Investigation loading** shares one pending streaming download per service instance, isolates caller cancellation, and clears failed loads for retry. A two-minute deadline bounds headers and body; successful results cache for 24 hours from completion. ([#44](https://github.com/cyanheads/nhtsa-vehicle-safety-mcp-server/issues/44))
