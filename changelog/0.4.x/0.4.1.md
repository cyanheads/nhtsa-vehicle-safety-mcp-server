# 0.4.1 — 2026-04-08

## Changed

- Bumped `@cyanheads/mcp-ts-core` ^0.3.2; `vitest` ^4.1.3
- Pinned patched transitive versions for `@hono/node-server`, `hono`, and `vite` to clear `bun audit` warnings
- Added regression coverage for sparse recall, complaint, safety-rating, and investigation payloads
- Updated package metadata and badges

## Fixed

- `nhtsa_search_recalls` and `nhtsa_get_vehicle_safety` now accept recall records when NHTSA omits `parkIt`, `parkOutSide`, or `overTheAirUpdate` ([#1](https://github.com/cyanheads/nhtsa-vehicle-safety-mcp-server/issues/1))
- `nhtsa_search_complaints`, `nhtsa_get_safety_ratings`, `nhtsa_search_investigations`, and `nhtsa_get_vehicle_safety` now preserve sparse upstream NHTSA fields instead of fabricating default values
