# 0.8.1 — 2026-05-31

## Added

- **`AQ` ("Audit Query")** added to `INVESTIGATION_TYPE_MAP`; `investigationType` filter description and tool description now list all named ODI type codes (PE/EA/DP/RQ/AQ) and document additional valid raw codes (SQ/EQ/RP/ID/TA/C). Codes without an authoritative NHTSA expansion retain the raw-code fallback. ([#16](https://github.com/cyanheads/nhtsa-vehicle-safety-mcp-server/issues/16))

## Fixed

- **`NhtsaService.getInvestigations`** — ODI flat file now decoded as UTF-8 (was `latin1`); multi-byte characters such as curly quotes (U+2018/U+2019, U+201C/U+201D) and em dashes in investigation subjects and summaries are no longer returned as mojibake. ([#15](https://github.com/cyanheads/nhtsa-vehicle-safety-mcp-server/issues/15))
- **`mergeFlatInvLine`** — `investigationType` extraction regex widened from `/^([A-Z]{2,3})/` to `/^([A-Z]+)/`; 1-letter prefixes (e.g. `C`) are no longer silently dropped, returning `undefined`. ([#16](https://github.com/cyanheads/nhtsa-vehicle-safety-mcp-server/issues/16))
