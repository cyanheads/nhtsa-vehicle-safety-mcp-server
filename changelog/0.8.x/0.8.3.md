# 0.8.3 — 2026-06-12

## Added

- **`scripts/clean-mcpb.ts`** — post-pack MCPB bundle cleaner wired into `bun run bundle`. Runs `mcpb clean` (dev-dependency prune + manifest validation), then strips dependency-shipped agent-doc entries nested under `node_modules/` (`skills/`, `.claude/`, `.agents/`, stray `SKILL.md`) that root-anchored `.mcpbignore` patterns cannot reach, and asserts zero remain.
- **`Dockerfile`** — `HEALTHCHECK` polling `/healthz` on `MCP_HTTP_PORT`, and an `APP_VERSION` build arg surfaced as the `org.opencontainers.image.version` OCI label.
- **Framework antipattern rule `coerce-boolean-env-flag`** — `scripts/check-framework-antipatterns.ts` now flags `z.coerce.boolean()` in `src/` (`Boolean("false")` is `true`, so env flags can't be disabled — use `z.stringbool()`); comment lines are skipped so JSDoc naming the pattern doesn't false-positive.

## Changed

- **`@cyanheads/mcp-ts-core`** `^0.9.21` → `^0.10.6`.
- **`createApp()`** — sets explicit `name` and `title` (`nhtsa-vehicle-safety-mcp-server`) so the display identity is the hyphenated repo name rather than a derived fallback.
- **`scripts/lint-packaging.ts`** — adds a post-bundle content check asserting no agent-doc entries ship in the `.mcpb`, sharing the `AGENT_DOC_ENTRY` pattern with `clean-mcpb.ts`.
- **`.mcpbignore`** — patterns root-anchored (`/.claude/`, `/skills/`, `/Dockerfile`, …) so they match only top-level entries.
- **`CLAUDE.md` / `AGENTS.md`** — drop the `ctx.sample` presence-check note from the elicit guidance.
- **Skills** — synced to the installed framework version; adds `skills/techniques/`.
