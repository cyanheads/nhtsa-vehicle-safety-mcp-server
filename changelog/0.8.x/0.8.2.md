# 0.8.2 — 2026-06-02

## Changed

- **`@cyanheads/mcp-ts-core`** `^0.9.16` → `^0.9.21` — adopts three framework fixes: per-request logs and traces now carry fresh request + trace/span IDs instead of the frozen boot context (HTTP transport); `fetchWithTimeout` strips query-string secrets (e.g. `?api_key=`) from error messages and logs; `withRetry` fails fast on non-retryable errors and `ctx.fail` auto-populates the `retryable` flag.
- **`scripts/devcheck.ts`** — updated to latest devcheck template.
- **`scripts/release-github.ts`** — new script backing `bun run release:github`; creates GitHub Releases from the current annotated tag with `.mcpb` attachment.
- **`scripts/check-skill-versions.ts`** — new skill version drift detector, now part of devcheck.
- **Plugin manifests** (`.claude-plugin/plugin.json`, `.codex-plugin/mcp.json`) — simplified `npx` args: removed redundant `run start:stdio` suffix.
- **`README.md`** client-config key renamed from `nhtsa-vehicle-safety` to the full package name `nhtsa-vehicle-safety-mcp-server`.
- **Skills** — `add-tool`, `add-service`, `api-canvas`, `api-context`, `api-linter`, `api-utils`, `design-mcp-server`, `release-and-publish` updated; `api-mirror` and `orchestrations` added.

## Dependencies

- `@cyanheads/mcp-ts-core` ^0.9.16 → ^0.9.21
- `vitest` ^4.1.7 → ^4.1.8
